I'm Andrew Chiw. I port old-architecture software using modern AI tooling, and I trade.

Current project: **Go for 32-bit PowerPC (darwin/ppc)**. `darwin/ppc64` already self-hosts and passes the test suite on a Powermac G5 Quad; the G3/G4 32-bit path is where the real pain lives. The work is done by a fleet of AI agents that I supervise more closely than I'd like to admit.

Machines in rotation:

- Powermac G5 Quad — loud, hot, crashes every ~2.5 days, wonderful
- iBook G4 1.2GHz — the reliable one; once ran an agent's filesystem test suite against itself
- Thinkpad running QEMU `ppc` / `ppc64` — where most debugging actually happens
